# ที่มาและประวัติการพัฒนา

โปรเจกต์เริ่มจากหน้าเว็บนับถอยหลัง 5 วันสำหรับใช้เป็นเครื่องมือเตือนตัวเองและสร้างแรงกดดันเชิงบวกให้เห็นเวลาที่เหลือชัดเจน แนวคิดหลักคือให้ตัวเลขเป็นจุดเด่นที่สุด แล้วใช้แถบเปอร์เซ็นต์ ฉาก และตัวละครเป็นสัญญาณรองที่ช่วยให้ผู้ใช้รู้สึกถึงการเคลื่อนของเวลา

ระหว่างการพัฒนามีการทดลองแสดงเวลาเป็นมิลลิวินาที แต่ถูกถอดออกเพราะทำให้ข้อมูลแน่นและอ่านยาก จึงเปลี่ยนเป็นตัวเลขวัน ชั่วโมง นาที และวินาทีที่อ่านได้ทันที พร้อมเปอร์เซ็นต์ทศนิยมสองตำแหน่งและแถบที่ลดลงอย่างต่อเนื่อง

ต่อมามีการเพิ่มการกำหนดวันและเวลาสิ้นสุด การบันทึกอัตโนมัติ การปรับความโปร่งของกรอบ พื้นหลังที่ผู้ใช้เลือกเอง และธีมที่เปลี่ยนเฉดตามภาพพื้นหลัง จากนั้นจึงเพิ่ม Pixel Journey เพื่อให้การนับถอยหลังมีบริบททางอารมณ์มากขึ้น ตัวละครจะเดินทางผ่านฉากและเปลี่ยนจังหวะตามเวลาที่เหลือ

ระบบวิดีโอและรูปภาพถูกแยกออกจากหน้าหลักเพื่อให้ Countdown ยังคงเป็นสิ่งที่เด่นที่สุด มีปุ่ม `need motivation?` สำหรับเปิดวิดีโอ และมีหน้าต่างรูปภาพแยกสำหรับการใช้งานต่อเนื่อง

เมื่อ Windows Smart App Control บล็อกไฟล์เดสก์ท็อปที่ไม่ได้เซ็น จึงสร้าง Countdown Browser เป็นรุ่น local-first ที่เปิดผ่าน Microsoft Edge แทน ข้อมูลหลักยังเก็บในเครื่องและใช้เวลาสิ้นสุดแบบ absolute timestamp ทำให้การปิดและเปิดใหม่ไม่ทำให้เวลาย้อนกลับ
